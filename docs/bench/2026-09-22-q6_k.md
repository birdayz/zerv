## Matched measurements

Actual output.weight [5120,248320], 1,042,944,000 packed bytes. Measure only the
first **1, 64, and 4096 rows**, not the entire vocabulary tensor. Largest output
is 80 MiB, input 17,203,200 bytes. Full model-file SHA verified; each slice's entire
input/output hashes agree with independent ctypes decoding and both timed engines
on every trial.

Native and external test-only C loops use readonly mmap input, reused/preallocated
output, direct synchronous calls and compiler barriers. No allocation/hash/I/O/
Python in timed loops. Reference public ggml type-traits to_float is resolved once;
native additionally prevalidates finite scales. 3 warmups, 7 trials, 3 alternating
rounds (21 observations per engine/shape), 10,000/256/4 calls per trial.

isolation or clock changes. Zig0.16 ReleaseFast/native, GCC16.2.1 O3/native external
adapter, unchanged installed ggml. Exact build/model/library/header/source/dependency
